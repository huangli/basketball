# spec：标注页提效（同组看一判全 + 默认 2 倍速）

日期：2026-08-09　状态：待实施　提出：立哥选型"1+3"（见会话记录）

## 背景与目标

批次 3 实测：234 事件逐条看片标注，立哥判 61 J（含 10 条同球重复）→ 51 球。
时间大头 = 逐条看 12 秒片段。dedup-same-goal 已落地"同组标黄 + 导出多 J 确认"，
本次在其上做两个提效功能，目标：**下批次（批次 4）标注耗时降 40% 左右**。

两个功能都在 `scripts/gen_label_page.py` 生成的 label.html 内，纯前端改动，
不动检测/切片/合并任何上游环节（召回红线不碰）。

## F1：同组看一判全

**现状**：疑似同回合组只标黄，组内每条都要看、都要判。批次 3 有 48 组 111 个
事件在组内，其中 8 组是同球双 J（同一入网看两遍）。

**功能**：立哥对某组内事件按 J（判进球）后，若该组还有**未标注**的其他成员，
页面弹确认框：

> 该事件属疑似同回合组 N（共 M 个，还有 X 个未标注）。
> 若刚才看到的入网画面就是这一组的全部内容，可把其余 X 个标为"不是进球"并跳过。
> 确定 = 其余标 F 并跳到下一个未标注事件
> 取消 = 不动，稍后逐条看

- 只对**未标注**成员生效；已标注成员（无论 J/P/F）一律不覆盖——防止误改已判事件
- 仅"本次为新标注"时触发确认框：对已标 goal 的事件重复按 J 不再弹框
- 标 F 语义 = "不是（新）进球"，与批次 3 立哥手工处理同球双 J 的做法一致
- 确认后自动跳到组外下一个未标注事件（复用现有 mark() 的 findIndex 逻辑，
  被标 F 的成员自然被跳过）
- 组内真是两个球（203918/203928 类反例）时：立哥点"取消"逐条看即可，
  或事后把误标的 F 改回 J——localStorage 记录可改，无数据损失
- 导出时的"同组多 J 确认框"（dedup 已交付）保留不动，作为兜底

**不做**：不自动跳过、不默认勾选、不覆盖已标注成员、跨文件组不特殊处理
（跨文件组本来不入组，见 dedup-same-goal spec）。

## F2：默认 2 倍速

**现状**：生成页 `<video>` 未设 playbackRate，常速播放。

**功能**：页面加载及每次换片后 `playbackRate = 2`；加 S 键在 1x / 2x 间切换
（状态显示在页面上，与"声音：开/关"同样式）。

**范围修正（对当初承诺的诚实更正）**：原选型描述含"自动跳到锚点前 2 秒"，
核实后发现审核片段本身就是 `[锚点−2s, 锚点+4s]`（`gen_review_clips.py:50`
CLIP_BEFORE_SEC=2.0），跳到锚点前 2 秒 = 跳到片头，**零收益，不做**。
F2 只交付默认 2 倍速 + S 键切换。

## 成功标准

1. F1 回放验证：用批次 3 的 234 事件 + `20260722地平线/goals_20260722_3.json`
   （61 条 confirmed = 立哥原始 J 标注，精确匹配事件）模拟"按页面顺序标注、
   遇组内 J 即确认跳过"。两个断言：
   - 自动跳过事件数 **≥ 8**（8 组同球双 J 各省 1 条是下限）；
   - **覆盖式断言**：模拟结束后，`work/20260722/goals_batch3.json`
     （去重后 51 球）每个球至少仍有一条 goal 事件（同球重复事件视为同一球；
     同球双 J 组内无论先遇到哪条，球都被先遇到那条的 J 捕获，不算误标）。
2. F2：生成页含 `playbackRate = 2` 且 S 键可切回 1x；`node --check` 语法通过。
3. 质量关口：`ruff format` + `ruff check --fix` + `pytest -q` 全绿。
4. 人工验收（立哥）：用批次 3 的 events_index 重新生成 label.html，抽一组
   同回合事件实操：按 J → 弹确认 → 确定 → 同组其余标 F 且跳过；S 键切速生效。

## 风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| 组内真两球被顺手标 F | 中 | 确认框文案写明"若画面相同才确定"；可改判；导出兜底确认框保留 |
| J 确认跳过后又把该 J 改判 F/P | 低 | 被自动标 F 的成员不复活，需手动回看；导出兜底确认框仍在，行为可接受 |
| 确认框打断标注节奏 | 低 | 仅组内 J 触发（批次 3 占比 111/234 事件中的 J 更少）；confirm 是浏览器原生，回车即确定 |
| 2 倍速看不清入网 | 低 | S 键一键回 1x；立哥审核视频本就用 2 倍速稳判 |
