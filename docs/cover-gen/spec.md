# Spec: 视频封面生成（cover-gen）——【已下线】

> **状态：已下线（2026-08-30 立哥定）。**
> 背景：原方案为每条输出视频自动抽帧（入网前 0.5s）+ 合成多张 3:4 候选封面供挑选，
> 用于发抖音/视频号。立哥实测后拍板：**封面图片选取还是人做比较好**，自动抽帧选取
> 无法取代人工判断"哪帧有张力"，功能下线。
> 处置：`scripts/gen_covers.py`、`tests/test_gen_covers.py`、`video covers` 子命令及
> 相关测试均已删除；本文件夹（含 review01/review02/plan.md/todo.md）留档不再维护。
> 出处：`docs/经验教训.md` §2。

## 原目标（留档）

- 给每条 confirmed roster 模式的 build 输出视频（队伍集锦 + 每个个人合集）生成每个
  confirmed 球一张封面（入网前 0.5s 抽帧），3:4 竖版 1080×1440，叠队伍名 + 片名，
  带编号网格预览 sheet.jpg 供人工挑选。
- 未认人自动模式只出颜色队队伍集锦封面；便服队不出；无过滤缺省 = 等价 build --all。

## 下线原因

- **人工审美不可替代**：哪一帧"最有张力/最能当封面"是主观判断，机器抽固定偏移
  （入网前 0.5s）无法保证挑中理想画面；人工从视频里选帧更可靠，成本也可接受。

## 保留产物（已生成，不再维护）

- `output/<场次>/covers/` 下已生成的封面 jpg 与 sheet 若仍有用途可继续使用；
  `output/` 已在 `.gitignore` 忽略，不会入库。
