# Spec: 标注页慢放视角（0.5x 短片段）

> 2026-07-30。依据：批次 2 标注中立哥报告 47/185 事件「时间太短判不了是否进球」。
> 2 倍速审核片段下入网瞬间仅 0.1~0.2s，人眼无法稳定判读。

## Objective

给 label.html 增加第三个视角「慢放 (S)」：每事件一段 0.5 倍速、筐居中、
锚点前后 ±1.5s 的短片段（实长 3s → 播放 6s），用于对 2x 片段判不了的事件做终判。
成功 = 立哥对 47 个待定事件全部能给出 J/P/F 判定，无「看不出来」残留。

## 范围与边界

- 只加不改：events_index 仅新增 `clip_slow` 字段（加字段兼容，语义不变）；
  label.html 既有 J/P/F/W/翻页/位置记忆行为不变
- 慢放片段从**原片**重新裁剪（不复用 2x 片段——已丢一半帧，再放慢会糊），
  **全景取景**（立哥 2026-07-30 拍板：全景比筐区裁剪更适合人类判读，与标注页默认视角一致）
- 慢放片段不带音频（0.5x 音调失真无价值，`-an`）
- 不改动批次 1 封存产物；本功能先在批次 2（185 事件）启用

## 设计

1. `gen_review_clips.py` 新增 `--slow-clips` 选项：在 `--keep-clips` 模式下，
   每事件额外产出 `clips/<fid>_eN_slow.mp4`（窗口 [anchor−1.5s, anchor+1.5s]、
   与主片段相同的自适应筐裁剪、setpts×2.0 慢放、fps=30、-an），
   并在 events_index 事件 dict 写入 `clip_slow` 相对路径。
2. `gen_label_page.py`：事件含 `clip_slow` 时增加「慢放 (S)」按钮与 S 键，
   三视角循环（筐区 ↔ 投球人 ↔ 慢放），视角切换不重置标注状态；
   无 `clip_slow` 字段的旧 index 不显示该按钮（向后兼容）。

## Success Criteria

1. ruff + pytest 全绿（新增纯函数测试：clip_slow 字段写入、页面含 S 控件逻辑）
2. 批次 2：185 个事件全部有 `_slow.mp4`（ffprobe 抽查：时长 ≈6s、30fps、无音轨）
3. label.html 打开后 S 键可在三视角间切换，标注进度（localStorage）不受影响
4. 立哥用慢放视角把 47 个待定事件标完（验收由他执行）

## Open Questions

无（慢放倍率 0.5x 与 ±1.5s 窗口若实测不够，参数化调整即可，不改架构）
