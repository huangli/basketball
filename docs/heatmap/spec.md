## 落点口径（v3 核心定义，写死）

**落点 = 投篮者人框底边中点（像素）→ 筐锚相对坐标。**两路并集，主路优先：

- **主路（追人链）**：种子 = 认人同逻辑定位框（find_held_box 或
  start_nearest_box）→ `trace_person` IoU 链回追 → 取链上最接近
  **anchor−1.0s** 的帧（容差 ±0.3s，5fps 即 ±1.5 帧）→ 该帧人框底边中点。
  anchor−1.0s = 出手时刻固定估计（球飞行 0.5~1.5s 的中值；粗糙但稳定，
  接球就投/急停跳投场景出手前 1s 人已基本站定）
  - **结构性上限声明（S2）**：trace_person 窗口 = 种子帧前后各 2.0s 写死
    在 crop_scorers（不改对外行为）。种子帧早于 anchor−3.0s 时目标帧
    越出窗口，链再活也够不到——59% 实测已含此天花板，不靠扩窗提覆盖
- **兜底（完整轨迹）**：主路链断（±0.3s 内无链上帧）且进球轨迹起点
  ≥0.8s 在锚点前时，取轨迹起点帧的**最近人框**底边中点
  （球离手点最近的人必在出手点 1~2m 内，物理约束不依赖"谁"；
  最近人框可能是防守人，无同色校验——报告声明此噪声，O4）
- 两路都无 → 记 uncovered，如实进报告（不硬凑）
- **串人守卫（S1 更正接口）**：链上目标帧人框与种子框做颜色队别校验——
  用 `team_of_box`（整帧图 + 人框，crop_scorers:1118），两者分类明确相反
  （黑↔白）时主路不可用、**视同链断走兜底**（plan 审查写死：两路并集的
  精神是主路不行走兜底，兜底为独立几何约束不受链污染）；"便服"判定
  不触发剔除（与认人 drop_opposite_team 同口径）。
  **帧图因此进入主路径依赖**（不只目击拼图用）
- 广告静物风险（S6）：同场次已实测 IoU 链会漂到场边广告"人形"静物
  （经验教训 §3），颜色守卫防不住（广告归便服不剔除）——列入目击判据
  （"框是不是真人"）与报告风险项

## 坐标口径（粗配准，写死）

**不做单应、不做人工点位**（Q1 路线封存）。逐球相对坐标：

- 原点 = 该球锚点时刻的**筐心像素**（hoops 事件 track 按采样时刻最近取值；
  多事件 window 同时覆盖锚点时，取采样时刻距锚点最近者，仍并列取锚点
  空间距离最近者——S4 写死取舍；**零覆盖时**（无 window 含锚点，实测 1 球）
  取采样时刻距锚点最近的 detected 事件并记 WARNING——J1 写死分支）
- **筐端归一化（B1，全场双筐必须做）**：hoops 锚点 cx 聚成两端（按 cx
  中位切分；本场双峰实测 P25=560/P75=1265）；统一归一到 **cx 均值较小端**
  ——较大端事件的落点 (dx, dy) 绕筐心旋转 180°（取反）。翻转标记
  （flipped: bool）逐球落盘并进报告；不做归一会把一端进球镜像到篮板后，
  系统性污染热图
- 尺度 = 该落点帧**人框高** ÷ 假设身高 1.75m（像素→米，逐球局部尺度；
  人框截断/遮挡会带噪声，接受并在报告声明；人框贴边时底边中点与框高
  双失真，落点噪声一并声明——O5）
- 方向：不校正旋转——同场次同机位（场边固定），画面水平轴 ≈ 场地
  边线方向，镜头变焦/平移由筐心+尺度吸收
- 输出 (dx, dy) 米制相对坐标；渲染时映射到 matplotlib 标准半场模板
  （筐心对齐模板筐心）

## 队别口径（B2 写死）

- team = roster assignments 值（tag）→ players 按 tag 查 `team` 字段
- 本场队伍集合动态取 players 的 team 去重（实测：车百鼎/半截篮/便服）；
  team 为"便服"的归属（实测 2 球）**不进热图**，逐球 WARNING 并在报告
  注明数量；队伍集合变化时热图按实际集合出图（不写死队名——K3）
- tag 查不到 team → WARNING 记 uncovered（数据损坏苗头，不静默）
- 队名渲染用 roster 原值（"车百鼎" / "半截篮"）
